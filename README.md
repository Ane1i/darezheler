# darezheler
Бұл сайт 7-сынып оқушыларына арналған «Дәреже» тақырыбын түсіндіруге көмектеседі. Мұнда дәреженің анықтамасы, қасиеттері, есеп шығару үлгілері және негізгі формулалар берілген. Сайтта теориялық материалдармен қатар, оқушылардың білімін тексеруге арналған қызықты тапсырмалар мен тесттер ұсынылады.
